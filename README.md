# SymCheck-Africa
SymCheck Africa is a mobile-friendly health screening tool that helps users identify possible illnesses based on symptoms. By matching input symptoms to a curated database of conditions and urgency levels, it empowers individuals—especially in underserved African communities—to make informed decisions, reduce drug misuse caused by self-medication.
